# 02-flashcard

A simple and interactive flashcard application built with **React 19** and **Vite** to help users learn and revise fundamental React concepts through an engaging question-and-answer experience.

## Overview

The React Flashcard Application provides a collection of interactive study cards covering essential React concepts. Each flashcard displays a question on the front, allowing users to click the card to reveal its corresponding answer.

This project demonstrates fundamental React concepts, including functional components, state management, event handling, conditional rendering, and dynamic content rendering.

## Features

- **Interactive Flashcards** – Click on a flashcard to reveal its corresponding answer.
- **Question and Answer Format** – Each flashcard contains a question and its relevant explanation.
- **Toggle Functionality** – Click the selected flashcard again to return to the question.
- **Dynamic Rendering** – Flashcards are generated dynamically using JavaScript's `map()` method.
- **State Management** – React's `useState` hook manages the currently selected flashcard.
- **Responsive Layout** – Flashcards are arranged using a flexible CSS layout.
- **Smooth Transitions** – CSS transitions enhance the overall user interaction experience.
